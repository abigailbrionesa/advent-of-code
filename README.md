# Advent of Code 2025 Solutions

<p>
Advent of Code is a Python solutions archive for the 2025 puzzle season. The repository keeps each day and part in a small script, paired with example and puzzle input files for fast review.
</p>

<p>
Built with <strong>Python scripts, text inputs, and algorithm-focused problem solving</strong>.
</p>

<img alt="Python" src="https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white">
</p>

## Highlights

<ul>
  <li>One-file-per-part organization for days 1 through 12 currently present.</li>
  <li>Example and full puzzle inputs kept beside each solution script.</li>
  <li>Readable procedural implementations for loops, parsing, arithmetic, and grid-style reasoning.</li>
  <li>Portfolio-friendly record of daily algorithm practice.</li>
</ul>

## Quick Start

<pre><code>python day1part1.py
python day1part2.py</code></pre>

## Project Structure

<pre>dayNpartM.py - Individual puzzle solutions
inputN.txt - Full puzzle input for a day
inputNexample.txt - Example input for local checks</pre>

## Validation

<p>
Run the relevant <code>dayNpartM.py</code> file from the repository root.
</p>

## Scope Notes

<p>
This is a solutions archive, not a packaged Python library; commands are intentionally per-puzzle.
</p>
